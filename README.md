# 📈 Higher Lower Game

A command-line implementation of the popular **Higher Lower** game built with Python.

The objective is simple: compare two famous people or brands and guess which one has more social media followers. The game continues until the player makes an incorrect guess.

This project was built as part of my Python learning journey.

---

## ✨ Features

- 🎮 Interactive command-line gameplay
- 🎲 Random account selection
- 📊 Score tracking
- 🔄 Continuous gameplay until a wrong answer
- 👥 Famous people and brands dataset
- 💻 Simple and lightweight
